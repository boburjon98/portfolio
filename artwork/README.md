## Shared prompt template

Consistent art direction: deep charcoal navy #080c13 background, mint teal accent light #b5f3c7 and restrained cool blue rim light, sophisticated materials, clean central composition, generous quiet margins for crop, crisp realistic textures, soft volumetric lighting, subtle depth of field. Full-bleed artwork, no panels, no collages, no watermark, no logo, no headings or UI text. This is conceptual project cover art, not a real product screenshot.
